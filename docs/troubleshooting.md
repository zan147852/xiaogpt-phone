# 常见问题

[返回首页](../README.md) · [安装指南](installation.md)

| 现象 | 检查与处理 |
|---|---|
| 先听到“小爱不会”，再听到模型回答 | 当前云端转接路径的已知限制，不能保证完全消除 |
| 追问没有接上 | 每轮仍需唤醒词；第一句“请／帮我”，后续在上轮回答后 90 秒内提问 |
| 自动记忆没有询问 | 只识别明确第一人称偏好和习惯；候选已保存、5 分钟冷却中或表述不匹配都可能不问；可用“记住……” |
| 说“记住这条”提示没有等待确认 | 建议已过 120 秒、换过话题或服务重启；重新说明要记住的内容 |
| 查看记忆只有 5 条 | 播报的是最近 5 条；总数会同时读出，可按编号或唯一内容删除 |
| 回答中间停顿 | 上游 TTS 的播放等待、小米控制往返或模型出句间隔均可能造成；保持短回答，网络稳定后再比较 |
| 熄屏后不回答 | Termux 后台、省电策略和应用自启动权限需检查；输入 `xiaoai status`，必要时 `xiaoai start` |
| 手机重启后不回答 | 先 `xiaoai start` 恢复，再按安装指南配置 Termux:Boot；仅授予 Termux 自启动权限不够 |
| 自启脚本已启用但没有运行 | 确认 Termux:Boot 同来源、安装后打开过、首次解锁完成，且系统允许其自启动；查看 `xiaoai autostart status` |
| waiting_for_network / boot_network_timeout | 等待 Wi-Fi；超时后联网执行 `xiaoai start`。不会在断网时反复登录小米 |
| 找不到 `xiaoai` | 安装没完成或当前不在 Termux；检查安装输出，修复错误后重试 |
| `container ubuntu is not installed` | 容器名称是 `xiaogpt`，不是 `ubuntu` |
| `--name` 不认识 | 升级到 PRoot-Distro 5.x，再运行安装器 |
| Python 依赖下载很慢／中断 | 检查空间和网络后重跑安装；语言检测依赖较大，勿把下载中断当作音箱不兼容 |
| Ubuntu 校验失败 | 不使用损坏文件；按安装器提示移走归档后从官方地址重新下载，不跳过校验 |
| 小米验证码失败 | 用本轮新验证码；不要频繁登录或连续重复尝试 |
| IoT 接口 -127 / client withdraw | 不绕过或反复重试；默认自动唤醒已关闭，普通 MiNA 播报可能仍可用 |
| 新音色请求成功却不出声 | 成功应答不等于播放；手机和音箱需局域网互通。S12 样本用 URL type 1；以实际拉取和试听为准 |

## 自检

```bash
xiaoai status
xiaoai check-stream
```

`check-stream` 会发一次真实、简短的模型请求，可能产生少量费用；只报告时间统计，不输出正文。`voice-sample` 会播放固定公开样本，不改变日常音色。

状态文件不等于进程存活保证。菜单会同时检查服务锁；若状态还写着 listening，但进程锁未占用，尝试 `xiaoai start`。

## 提交问题前

请提供手机型号、Android 版本、音箱型号、`xiaoai status` 的状态词、出现问题的步骤和不含隐私的错误类别。不要粘贴账号配置、token、API 密钥、验证码、私人记忆或完整对话。

无需为了反馈问题重新触发小米登录。先确认是否属于首页列出的已知限制。
