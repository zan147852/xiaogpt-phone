# 隐私与记忆

[返回首页](../README.md) · [记忆管理指令](usage.md#记忆和偏好)

## 数据位置

账号、密码、API 密钥、小米令牌、长期记忆位于容器内 `/root/.config/xiaogpt/`，对应 Termux 的 Android 应用私有存储。目录权限 700、文件权限 600。数据**没有做额外应用层加密**，获得手机解锁和调试权限的人仍可能访问它们。

| 数据 | 保留方式 |
|---|---|
| 完整问答 | 默认不写日志；最近 5 轮仅在进程内存 |
| 自动记忆候选 | 只在内存，120 秒、换话题或重启后失效 |
| 已确认长期记忆 | SQLite，最多 100 条／每条 300 字 |
| 状态和完成次数 | 手机任务目录，不包含问答正文 |
| 部分控制错误 | 类型、错误码、分类；不记录完整网络响应 |
| 新音色诊断 | 固定样本的局域网 URL 和请求计数；不是对话录音 |

## 外部平台

语音识别和控制走小米服务；模型输入走用户选择的 HTTPS API。当前检索最多选取 8 条、1600 字记忆作为上下文，可能包含与本问题无关的最近记忆。请只保存你愿意提供给模型平台的内容。

默认原声无需本项目额外调用微软服务。固定音色样本会发送到微软 Edge TTS；自行改成外部音色后，回答文本也会流向相应语音平台。

“未记录本地聊天”不代表小米或模型平台不保留服务记录。各平台的数据政策应自行确认。

## 删除与关闭

说“查看记忆”找到内容，按“忘记编号3”删除；全部删除需“清空记忆”后 30 秒内“确认清空记忆”。删除指令同时清除当前模型上下文。SQLite 开启 `secure_delete`，但这不保证闪存底层或其他备份中的内容无法恢复。

关闭自动建议：将 `AUTOMATIC_MEMORY_PROPOSALS` 改成 `False` 后应用设置。关闭不会删除已保存记忆，清空记忆也不会关闭以后提议的能力。

不要用语音存储密码、密钥、验证码、身份证或银行卡。程序有基础关键词拦截，但不能识别所有敏感信息和表达方式。

## 分享项目或报错

只分享仓库里的源码与文档。不要上传 `config.json`、`mi.token`、`memory.sqlite3`、配置目录、验证码、聊天正文或手机调试截图中的账号信息。`.gitignore` 和发布检查能减少误提交，不能替代人工检查。
