# 使用与设置

[返回首页](../README.md) · [隐私与记忆](privacy.md)

## 问答与追问

第一句以“请”或“帮我”开头，转给大模型并建立 90 秒追问状态。此期间后续问题无需重复前缀，但每轮仍需“小爱同学”。也可以说“开始聊天”手动进入、“结束聊天”退出。

90 秒从本轮回答完成后继续计算。最近 5 轮上下文只存在内存；长期记忆可以跨重启保存。语音识别准确度仍由音箱和小米服务决定。

## 记忆和偏好

偏好没有独立数据库，属于同一份长期记忆。

| 指令 | 效果 |
|---|---|
| 记住我喜欢清淡的饭菜 | 明确保存，最多 100 条，每条 300 字 |
| 查看记忆 | 读出总数和最近 5 条编号 |
| 忘记清淡的饭菜 | 匹配唯一一条才删除，多条匹配会提示按编号指定 |
| 忘记编号3 | 删除该编号 |
| 清空记忆 | 开始 30 秒确认窗口 |
| 确认清空记忆 | 窗口内删除全部 |
| 记住这条 | 确认当前尚未过期的自动建议 |
| 不要记 | 取消当前建议 |

自动建议只识别明确的第一人称偏好和习惯，不使用第二个模型，也不会保存全部聊天。5 分钟内最多询问一次，建议在 120 秒后或换话题时失效。类似“如果我喜欢……”或引用他人说法会尽量排除；规则不可能理解所有语境，确认前请听清它要保存的内容。

删除后会清除当前对话上下文；确认清空也是如此。清空不会关闭以后提出记忆建议的能力。查看记忆会通过音箱读出，请注意周围是否有人。

## 修改人格、自动记忆与回答长度

编辑仓库里的 `app/voice_settings.py`：

```python
CHAT_IDLE_SECONDS = 90
AUTOMATIC_MEMORY_PROPOSALS = True
```

将自动建议改为 `False`，就只在明确说“记住……”时保存；已有记忆仍保留。人格和表达要求在 `VOICE_SETTINGS['prompt']`。`gpt_options.max_tokens` 控制生成长度上限，中文字符与 token 并非一一对应。

修改后停止服务、重新运行安装器、再启动，参照[升级步骤](installation.md#升级)。如果直接编辑的是手机运行目录 `~/xiaogpt/voice_settings.py`，执行 `xiaoai apply-settings` 会停服、应用提示并重启。仓库文件与手机运行目录是两份，不会自动同步。

`AUTO_WAKEUP_ENABLED` 默认关闭。参考设备的自动唤醒接口曾被小米拒绝，不建议为追求免唤醒词而反复开启重试。

## 音色

默认使用小爱原声。原生播报接口只传文字，本项目不承诺直接调节原声的音高。

```bash
xiaoai voice-sample
```

该命令只合成并播放固定公开样本，不会替换日常音色；音箱和手机需能通过局域网访问。Edge 样本使用 `zh-CN-XiaoxiaoNeural`、正常语速、音高 -2Hz。参考设备已实际出声；外部语音合成会增加生成和音频拉取延迟。

目前没有日常音色切换菜单，避免把一次样本成功误当成持续播报已验收。若自行接入外部 TTS，需另测每段播放、失败恢复、局域网权限和回答文本的数据流向。

## 状态

| 状态 | 含义 |
|---|---|
| listening / listening_manual_wakeup | 等待提问，每轮仍需唤醒词 |
| answering | 正在生成／播报 |
| configuration_required | 需要完成向导 |
| connection_failed / needs_attention | 接口、网络或配置需检查 |
| stopped | 服务停止 |

完成回答次数表示软件播报流程返回，不代表音箱一定出声；请以试听为准。
